# Submission Checklist

- [ ] Follows required format (font, margins, spacing)
- [ ] Word / page count within limit
- [ ] Citation style consistent (APA / IEEE / other)
- [ ] All figures and tables numbered, captioned, referenced in text
- [ ] Every opinion backed by data or a citation
- [ ] Tool versions and dates reported
- [ ] Plagiarism check done
- [ ] No APKs or sensitive captures included
- [ ] Abstract written last and matches final results
- [ ] Proofread by one other person
